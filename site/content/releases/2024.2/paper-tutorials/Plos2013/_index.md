This section contains pages generated automatically from the source code accompanying [Chaste: an open source C++ library for computational physiology and biology](http://dx.doi.org/10.1371/journal.pcbi.1002970),
our paper in PLoS Computational Biology.

**The code has been updated to work with [Chaste v3.4](https://github.com/Chaste/Chaste/releases/tag/release_3.4)**

Before running these examples you will need to [install Chaste's dependencies](/docs/installguides/) and the [source code for version 3.4](https://github.com/Chaste/Chaste/releases/tag/release_3.4).
The easiest way to do this is using an Ubuntu machine (or an Ubuntu virtual machine) as discussed on [the Ubuntu installation guide](/docs/installguides/ubuntu-package/).

The paper is organised around four examples that are annotated and explained here.
Before looking at these, you may wish to look at some of the [basic user tutorials](/docs/user-tutorials/).

Click on the images below to go to the annotated code that defines the simulation for each case.
The code required to run these examples can be downloaded from [the project Git repository](https://github.com/Chaste/project_Plos2013).
For further information on using Chaste to solve these and related problems, see our [extensive guide material](/docs).
