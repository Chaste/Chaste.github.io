## Installing and Using Chaste via a Docker Container

Perhaps the easiest way to use Chaste is via [docker](https://store.docker.com/search?offering=community&type=edition).

We have a dockerfile in a separate Github repo at [https://github.com/Chaste/chaste-docker](https://github.com/Chaste/chaste-docker) and the readme there provides instructions for installing and using it.
