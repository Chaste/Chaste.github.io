A workshop on cell-based Chaste: an introduction to basic functionality, and a showcase of the latest additions to the codebase.

## Event details

**Where?**

Doctoral Training Centre  
1-4 Keble Road  
Oxford  
OX1 3NP 
UK

**When?**

Monday 11 September to Thursday 14 September 2023

## Timetable

### Monday 11 September
- Arrivals
- Introduction and welcome
- Lightning introductions from attendees
- Introduction to vertex models, and other cell-based paradigms
- Practical session, using the PyChaste python frontend for Chaste
- Getting familiar with Chaste terminology and code structure

### Tuesday 12 September
- Scientific case study #1 (TBC)
- Get up and running with Chaste in VS Code using Docker and C++
- Practical session, on how to use the C++ interface to make more substantial changes to models
- Scientific case study #2 (TBC)
- New functionality for implementing more detailed cell shape representations
- Overview of the new Chaste infrastructure, and how to access help and support
- Aside: an introduction to Research Software Engineering

### Wednesday 13 September
- Scientific case study #1 (TBC)
- Coupling cells/tissues to the microenvironment
- Scientific case study #1 (SRC models)
- Modeling cell-environment feedback
- Lightning wrapups from attendees
- Departures

### Thursday 14 September (optional hackathon)
- Bring your own project, or
- Get help from the Chaste development team to get started with a model
